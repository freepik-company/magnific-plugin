# Security policy

## Reporting a vulnerability

Report a vulnerability privately through this repository's **Security** tab: choose **Report a vulnerability**.
Do not open a public issue, pull request or discussion for it.

Include what you found, how to reproduce it, and what an attacker could do with it.
We confirm receipt, keep you informed while we fix it, and credit you in the advisory if you want.

## Scope

In scope:

- The skills, the `/magnific` command and the manifests in this repository, for example instructions that make an agent spend credits, share work or run commands the user did not ask for.
- `skills/product-imagery/scripts/packshot.py`.

The Magnific MCP server, sign-in and the Magnific apps are not code in this repository.
Report issues in them the same way, and we route them to the team that owns them.

## Supported versions

Only the latest release on `main` gets fixes.
